# Problem Discovery Framework

A decision is a call to connect a solution to a problem. This directory contains the **Problem Discovery Framework** for systematically discovering, identifying, and presenting problems and their solutions *before* they enter the Decision Tree.

## Overview

The Problem Discovery framework ensures we never make excellent decisions on the wrong problems. It precedes the Decision Tree by:

- **Discovering problems** through continuous capture and EB-25 prioritization
- **Identifying root causes** by stripping away solution-bias
- **Presenting solutions** through structured RFC methodology
- **Handing off** crystallized problem statements to the Decision Tree

## The EB-25 Methodology

The **EB-25 (Eisenhower-Buffett 25)** combines:
- **Eisenhower Matrix:** Filter by urgency and importance
- **Buffett's 5/25 Rule:** Strictly limit to 25 active problems (Top 5 + Next 20)

This ensures executive bandwidth is spent only on high-impact issues.
