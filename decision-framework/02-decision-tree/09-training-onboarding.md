# 9. Training and Onboarding

## Overview

This document outlines training and onboarding requirements for cofounders and board members to ensure effective use of the decision meta-framework.

**Key Principle:** Frameworks are only as effective as the people using them. Training ensures consistent, high-quality application.

## Cofounder Onboarding

### Training Program

New cofounders must complete a comprehensive training program before participating in framework-based decisions.

#### Module 1: Framework Overview (2 hours)

**Objectives:**
- Understand the meta-framework philosophy
- Learn the four-phase process
- Understand framework selection logic
- Review documentation requirements

**Content:**
- Read [01-executive-summary.md](./01-executive-summary.md)
- Read [02-framework-philosophy.md](./02-framework-philosophy.md)
- Review framework selection decision tree
- Understand documentation standards

**Deliverable:** Complete understanding quiz (90%+ pass required)

#### Module 2: State Gathering (1 hour)

**Objectives:**
- Learn alignment assessment
- Learn risk assessment
- Learn reversibility assessment
- Practice completing Decision Context Card

**Content:**
- Read [03-state-gathering.md](./03-state-gathering.md)
- Review Decision Context Card template
- Practice with sample decisions
- Understand common pitfalls

**Deliverable:** Complete 3 sample state assessments

#### Module 3: Framework Selection (1 hour)

**Objectives:**
- Learn framework decision tree
- Understand framework selection matrix
- Practice framework selection
- Learn when to escalate

**Content:**
- Read [04-framework-selection.md](./04-framework-selection.md)
- Review framework descriptions
- Practice framework selection with sample decisions
- Understand escalation triggers

**Deliverable:** Complete 5 framework selection exercises

#### Module 4: Framework Application (2 hours)

**Objectives:**
- Learn framework application rules
- Review all framework templates
- Practice framework application
- Understand sign-off requirements

**Content:**
- Read [05-framework-application.md](./05-framework-application.md)
- Review all templates in [`./templates/`](./templates/)
- Practice applying 3 different frameworks
- Understand common application mistakes

**Deliverable:** Complete 3 framework applications

#### Module 5: Special Protocols (1 hour)

**Objectives:**
- Learn Alignment Resolution Protocol
- Learn Escalation Protocol
- Learn Emergency Decision Protocol
- Understand when to use special protocols

**Content:**
- Read [06-special-protocols.md](./06-special-protocols.md)
- Review special protocol templates
- Practice protocol selection
- Understand protocol interaction with standard frameworks

**Deliverable:** Complete protocol selection quiz

#### Module 6: Retrospection (1 hour)

**Objectives:**
- Learn retrospection process
- Understand retrospection timing
- Practice completing retrospection template
- Learn quarterly review process

**Content:**
- Read [07-retrospection.md](./07-retrospection.md)
- Review retrospection template
- Practice retrospection with sample decisions
- Understand quarterly review requirements

**Deliverable:** Complete 2 retrospection exercises

#### Module 7: Documentation (1 hour)

**Objectives:**
- Learn documentation standards
- Understand Decision Register maintenance
- Learn investor due diligence package assembly
- Practice redaction

**Content:**
- Read [08-documentation-due-diligence.md](./08-documentation-due-diligence.md)
- Review documentation templates
- Practice Decision Register entry
- Practice redaction exercise

**Deliverable:** Complete documentation exercise

### Role-Playing Exercise (1 hour)

**Objective:** Apply framework knowledge in simulated decision scenarios.

**Scenarios:**
1. Type I, low-risk decision (use 5-Minute Rule)
2. Type II, medium-risk decision (use ASOFF)
3. Type III, high-risk decision (use Weighted Matrix)
4. Alignment resolution scenario
5. Emergency decision scenario

**Process:**
- Each cofounder plays a role
- Apply appropriate framework
- Complete documentation
- Receive feedback from trainer

**Deliverable:** Successful completion of all scenarios

### Knowledge Check (30 minutes)

**Format:** Multiple choice and short answer

**Topics Covered:**
- Framework philosophy and principles
- State gathering dimensions
- Framework selection logic
- Framework application rules
- Special protocols
- Retrospection requirements
- Documentation standards

**Passing Score:** 90%+

**Retake Policy:** Unlimited retakes, but must wait 24 hours between attempts.

### Onboarding Timeline

**Total Time:** Approximately 8-10 hours

**Scheduling:**
- Can be completed in 1-2 days
- Or spread over 1 week
- Must be completed before participating in framework-based decisions

**Prerequisites:**
- Access to all framework documents
- Access to templates
- Trainer availability (existing cofounder or external)

## Board Training

### Training Overview

Board members receive a streamlined training focused on oversight and escalation, not framework application.

### Module 1: Framework Overview (1 hour)

**Objectives:**
- Understand the meta-framework approach
- Learn the four-phase process
- Understand framework selection logic
- Review documentation standards

**Content:**
- Executive summary presentation
- Framework philosophy overview
- Framework selection decision tree
- Documentation standards overview

**Deliverable:** None (informational only)

### Module 2: Oversight and Escalation (1 hour)

**Objectives:**
- Understand Board oversight role
- Learn escalation triggers
- Learn escalation process
- Review escalation documentation

**Content:**
- Escalation protocol overview
- Board decision authority
- Escalation documentation review
- Sample escalation cases

**Deliverable:** None (informational only)

### Module 3: Review Access (ongoing)

**Objectives:**
- Access to Decision Register
- Access to framework documentation
- Understanding of review process

**Content:**
- Decision Register access training
- Framework document navigation
- Review process overview

**Deliverable:** Successful access to all review materials

### Board Training Timeline

**Total Time:** 2 hours (initial) + ongoing access

**Scheduling:**
- Completed before first Board meeting
- Refresher training annually

## Training Materials

### Training Deck

**Slides:**
1. Introduction and Philosophy
2. State Gathering
3. Framework Selection
4. Framework Application
5. Special Protocols
6. Retrospection
7. Documentation
8. Role-Playing Scenarios
9. Knowledge Check
10. Q&A

**Delivery:** In-person or video conference

### Training Exercises

**Exercise 1: State Gathering**
- Provide 3 sample decisions
- Ask trainee to complete state assessment
- Review and provide feedback

**Exercise 2: Framework Selection**
- Provide 5 sample decisions with state assessments
- Ask trainee to select appropriate framework
- Review and provide feedback

**Exercise 3: Framework Application**
- Provide 1 sample decision
- Ask trainee to apply specified framework
- Review documentation and provide feedback

**Exercise 4: Retrospection**
- Provide 1 completed decision with outcome
- Ask trainee to complete retrospection
- Review and provide feedback

### Knowledge Check Questions

**Sample Questions:**

1. What are the three dimensions of state gathering?
   - Alignment, Risk, Reversibility

2. Which framework is used for Type IV decisions?
   - STOP Protocol

3. What is the time investment for ASOFF?
   - 1-3 days

4. When is retrospection mandatory?
   - STOP, Alignment Resolution, Emergency, Escalation

5. What is the purpose of the Decision Register?
   - Master record of all executive decisions

## Training Quality Assurance

### Trainer Qualifications

**For Cofounder Training:**
- Must be existing cofounder with framework experience
- Must have completed at least 5 framework applications
- Must have completed at least 3 retrospections

**For Board Training:**
- Must be cofounder with framework experience
- Must have Board training experience
- Must understand escalation protocols

### Training Evaluation

**Post-Training Survey:**
- Training clarity (1-10)
- Training usefulness (1-10)
- Confidence in applying framework (1-10)
- Suggestions for improvement

**Follow-Up Assessment:**
- Assess trainee's first 3 framework applications
- Provide feedback and coaching
- Identify additional training needs if any

### Training Updates

**When to Update Training:**
- Framework documentation changes
- New frameworks added
- Frameworks removed
- Process improvements implemented
- Quarterly review identifies training gaps

**Update Process:**
1. Identify training updates needed
2. Update training materials
3. Update knowledge check questions
4. Retrain existing cofounders if significant changes
5. Document training updates

## Common Training Issues

### Issue 1: Rushing Through Training

**Symptom:** Cofounder wants to skip training or rush through it.

**Solution:** Training is mandatory. No framework participation until training complete.

### Issue 2: Knowledge Check Failure

**Symptom:** Cofounder fails knowledge check multiple times.

**Solution:** Provide additional coaching. Identify knowledge gaps. Adjust training if needed.

### Issue 3: Role-Playing Difficulty

**Symptom:** Cofounder struggles with role-playing exercises.

**Solution:** Provide additional practice scenarios. Pair with experienced cofounder for real decisions initially.

### Issue 4: Board Training Resistance

**Symptom:** Board members resist training or don't see value.

**Solution:** Emphasize oversight role, not application role. Keep training focused and concise.

## Training Records

### Cofounder Training Record

**Contents:**
- Training completion date
- Knowledge check score
- Role-playing exercise completion
- Trainer signature
- Retraining dates (if applicable)

**Storage:** Personnel file, secure location

### Board Training Record

**Contents:**
- Training completion date
- Training modules completed
- Access granted to review materials
- Trainer signature

**Storage:** Board file, secure location

## Next Steps

After training completion:

1. **Begin participating** in framework-based decisions
2. **Apply frameworks** under supervision initially
3. **Complete retrospections** for early decisions
4. **Provide feedback** on training effectiveness
